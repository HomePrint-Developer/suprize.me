suprize.me 🎁

Halaman web statis sederhana untuk berbagi hadiah dan tautan produk secara langsung dari Suprize.me.

✨ Fitur Utama

Desain Bersih & Responsif: Tampilan minimalis yang nyaman dilihat baik melalui smartphone maupun desktop.

Ringan & Cepat: Dibangun hanya dengan satu file index.html menggunakan Tailwind CSS CDN tanpa proses build yang rumit.

Akses Langsung: Tombol interaktif yang langsung mengarahkan penerima ke halaman produk Shopee terkait.

🚀 Cara Menjalankan & Deploy di GitHub Pages

Pastikan file utama halaman web tersimpan dengan nama index.html di dalam root repository ini.

Buka tab Settings pada repository GitHub Anda.

Pilih menu Pages di bilah navigasi sebelah kiri.

Pada bagian Build and deployment > Branch, pilih branch main (atau master) dengan folder / (root), lalu klik Save.

Tunggu beberapa saat hingga GitHub selesai memproses, dan halaman web Anda siap dibagikan!

🛠️ Kustomisasi

Jika ingin mengubah pesan atau tautan tujuan di kemudian hari, cukup buka file index.html dan sesuaikan bagian berikut:

Teks Pesan: Ubah teks di dalam tag <h1> dan <p>.

Tautan Shopee: Ganti URL pada atribut href di dalam tag <a> utama.
